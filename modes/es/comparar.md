# Modo: comparar — Comparación Multi-Oferta

Matriz de puntuación con 10 dimensiones ponderadas:

| Dimensión | Peso | Criterios 1-5 |
|-----------|------|----------------|
| Alineación North Star | 25% | 5=rol objetivo exacto, 1=sin relación |
| Match con CV | 15% | 5=90%+ match, 1=<40% match |
| Nivel (senior+) | 15% | 5=staff+, 4=senior, 3=semi-senior, 2=junior, 1=trainee |
| Compensación estimada | 10% | 5=cuartil superior, 1=debajo del mercado |
| Trayectoria de crecimiento | 10% | 5=camino claro a próximo nivel, 1=callejón sin salida |
| Calidad del remoto | 5% | 5=full remoto asincrónico, 1=solo presencial |
| Reputación de empresa | 5% | 5=empleador top, 1=banderas rojas |
| Modernidad del stack | 5% | 5=stack actual y relevante, 1=legado |
| Velocidad del proceso | 5% | 5=proceso ágil, 1=6+ meses |
| Señales culturales | 5% | 5=cultura builder, 1=burocrática |

Para cada oferta: puntaje por dimensión y puntaje total ponderado.
Ranking final + recomendación con consideraciones de tiempo.

**Para Argentina específicamente:**
- Compensación en ARS o USD según tipo de contratación
- Empresas locales vs contractor exterior pueden tener pesos de dimensión diferentes
- Estabilidad laboral (relación de dependencia) puede ser un factor adicional para algunos candidatos
- Considerar zona horaria para posiciones remotas internacionales (Argentina es GMT-3)

Todos los reportes deben incluir **URL:** y **Legitimidad:** en el encabezado.
