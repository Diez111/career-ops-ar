# Modo: entrenar — Evaluación de Curso/Certificación

Cuando el usuario quiere evaluar si un curso, certificación o bootcamp vale la pena para sus objetivos de carrera.

## Inputs necesarios

- Nombre del curso/certificación
- Institución/proveedor
- URL (si existe)
- Tiempo estimado de dedicación
- Costo (si aplica)

## Evaluación

### Bloque A — Relevancia para el Mercado Argentino

- ¿Qué peso tiene esta certificación en búsquedas locales?
- ¿La piden explícitamente en las JD que está viendo el candidato?
- ¿Es reconocida por recruiters/empresas locales?
- Comparar con certificaciones alternativas del mismo dominio

### Bloque B — Análisis Costo-Beneficio

| Factor | Detalle |
|--------|---------|
| Costo monetario | ARS / USD |
| Tiempo requerido | horas totales |
| ROI estimado | incremento salarial probable / nuevas oportunidades |
| Ventana de relevancia | ¿cuántos años va a ser valiosa esta skillset? |

### Bloque C — Alternativas

- Cursos gratuitos equivalentes
- Proyectos prácticos que cubran el mismo aprendizaje
- Certificaciones con mejor relación costo-beneficio
- Recursos en español vs inglés

### Bloque D — Veredicto

- **Hacelo** — alta relevancia, buen ROI
- **Hacelo si...** — condicional (ej: si conseguís descuento, si el empleador lo paga)
- **No lo hagas** — bajo ROI, alternativas superiores
- **Postergalo** — no es urgente, puede esperar

**Regla:** Siempre considerar el contexto del mercado argentino. Una certificación AWS pesa distinto que un bootcamp de 3 meses. Ser específico y dar números cuando sea posible.
